# GEBCO 2026

## Descrição

Conjunto de dados batimétricos do GEBCO — General Bathymetric Chart of the Oceans.

## Fonte

GEBCO — General Bathymetric Chart of the Oceans

https://www.gebco.net/

## Data de aquisição

19/07/2026

## Área geográfica

- Norte: 8° N
- Sul: 36° S
- Oeste: 60° W
- Leste: 28° W

## Estrutura

GEBCO
- Documentacao
- Downloads_Originais
- Raster
- DOWNLOAD_GEBCO.txt
- README.md

## Conteúdo

A pasta Raster contém o arquivo GeoTIFF utilizado no SIG.

A pasta Downloads_Originais preserva o arquivo ZIP obtido no portal do GEBCO.

A pasta Documentacao contém os documentos técnicos e os termos de uso.

## Formato dos dados

- Formato principal: GeoTIFF
- Unidade vertical: metros
- Valores negativos: profundidades
- Valores positivos: elevações
